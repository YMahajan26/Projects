<h1> Movie Recommendation System :</h1>
<b>Technologies Used:</b> Python, Streamlit, TMDb API, Machine Learning (Cosine Similarity)
<br><br>
 Developed a Streamlit-based application that suggests movies using a content-based filtering technique. 
 Integrates with the TMDb API to fetch and display movie posters, enhancing user engagement
